## github操作踩坑记录
1. 生成秘钥命令
```bash
# 核心生成命令（替换为你的GitHub注册邮箱）
ssh-keygen -t ed25519 -C "your_email@qq.com"
```
命令参数说明：
-t ed25519：指定密钥加密算法（推荐，比 rsa 更安全；若系统不支持，可替换为-t rsa -b 4096）；
-C：添加注释（通常填 GitHub 邮箱，方便识别密钥归属）

2. 执行命令后，终端会提示 `Enter file in which to save the key (/Users/你的用户名/.ssh/id_ed25519):`，直接回车（使用默认路径）；
3. 接着提示 `Enter passphrase (empty for no passphrase):`，建议输入密码更安全
4. 再次提示 `Enter same passphrase again:`重复输入密码
5. 公钥私钥
   | 类型 | 用途 | 后缀说明 |
   |--------|---------------|----------|
   | 私钥 | 保存在本地电脑，用于身份验证（不可泄露）| 无后缀（纯文本文件）|
   | 公钥 | 上传到 GitHub 账户，用于匹配验证 | 固定后缀.pub（公钥标识） |
7. GitHub 后台添加公钥
登录 GitHub 账号，点击右上角头像 → Settings（设置）；
左侧菜单栏选择 SSH and GPG keys；
点击 New SSH key（绿色按钮）；
填写配置：
Title：自定义名称（如「我的笔记本」），方便识别设备；
Key：直接粘贴刚才复制的公钥内容（无需加任何引号，粘贴后检查开头是 ssh-ed25519/ssh-rsa，结尾是你的邮箱）；
Key type：默认选 Authentication Key 即可；
点击 Add SSH key，输入 GitHub 密码验证完成添加

### 常见注意事项
1. 公钥内容必须完整，粘贴时不要遗漏字符，也不要手动添加引号、括号等符号；
2. 若添加后提示权限错误，检查公钥是否复制完整、GitHub 账号是否对应；
3. 多设备使用时，可添加多个公钥，通过 Title 区分不同设备。
