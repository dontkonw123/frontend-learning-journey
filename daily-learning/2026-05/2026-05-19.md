## pina学习

1. pinia 官网：`https://pinia.vuejs.org/`
2. 支持typescript一起使用
3. 在 Pinia 中，已经不存在 mutations，只有 state、getters、actions
4. 支持插件扩展，可以通过插件（函数）来扩展仓库的功能，为仓库添加全局属性或者全局方法
5. 更加轻量，压缩之后体积只有 1kb 左右，基本上可以忽略这个库的存在

## 面试题

 是否使用过 Pinia？简单谈一下 Pinia 的使用？

在 Pinia 中，核心概念有

- state：仓库的核心，主要是用于维护仓库的数据
- getters：用于对数据做二次计算的，等同于 store 的 state 的计算值
- actions ：对仓库状态进行操作的方法

相比 Vuex，Pinia 中没有 mutations，同步方法和异步方法都放在 actions 里面。Pinia 同时支持 Vue2 和 Vue3，内部支持两种编码风格，分别是：

- 选项式 API ：编码风格基本就和之前的 Vuex 是相似的
- 组合式 API ： 编码风格和 Vue3 非常相似，使用 ref 或者 reactive 来定义仓库数据，使用 computed 来做 getters，actions 里面的方法直接书写即可，最后将数据和方法通过 return 导出。

## github操作踩坑记录

1. 生成秘钥命令

```bash
# 核心生成命令（替换为你的GitHub注册邮箱）
ssh-keygen -t ed25519 -C "your_email@qq.com"
```

命令参数说明：
-t ed25519：指定密钥加密算法（推荐，比 rsa 更安全；若系统不支持，可替换为-t rsa -b 4096）；
-C：添加注释（通常填 GitHub 邮箱，方便识别密钥归属）

2. 执行命令后，终端会提示 `Enter file in which to save the key (/Users/你的用户名/.ssh/id_ed25519):`，直接回车（使用默认路径）；
3. 接着提示 `Enter passphrase (empty for no passphrase):`，建议输入密码更安全
4. 再次提示 `Enter same passphrase again:`重复输入密码
5. 公钥私钥

   | 类型 | 用途 | 后缀说明 |
   |--------|---------------|----------|
   | 私钥 | 保存在本地电脑，用于身份验证（不可泄露）| 无后缀（纯文本文件）|
   | 公钥 | 上传到 GitHub 账户，用于匹配验证 | 固定后缀.pub（公钥标识） |

6. GitHub 后台添加公钥
登录 GitHub 账号，点击右上角头像 → Settings（设置）；
左侧菜单栏选择 SSH and GPG keys；
点击 New SSH key（绿色按钮）；
填写配置：
Title：自定义名称（如「我的笔记本」），方便识别设备；
Key：直接粘贴刚才复制的公钥内容（无需加任何引号，粘贴后检查开头是 ssh-ed25519/ssh-rsa，结尾是你的邮箱）；
Key type：默认选 Authentication Key 即可；
点击 Add SSH key，输入 GitHub 密码验证完成添加

### 常见注意事项

1. 公钥内容必须完整，粘贴时不要遗漏字符，也不要手动添加引号、括号等符号；
2. 若添加后提示权限错误，检查公钥是否复制完整、GitHub 账号是否对应；
3. 多设备使用时，可添加多个公钥，通过 Title 区分不同设备。
4. 若第3步骤设置了密码，每次使用 git 命令时，都需要输入密码验证，建议取消密码（可选）
取消密码命令：`ssh-keygen -p -f ~/.ssh/id_ed25519`,输入旧密码，然后输入新密码（直接回车即可，表示不设置密码）
